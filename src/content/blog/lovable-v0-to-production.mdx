## Week 0 — Safety and scope

- Rotate any key that touched the repo or client bundle.
- Delete unused routes and components from the export.
- Write down the three user journeys that must work for launch—ignore the rest until v2.

## Week 1 — Auth and tenancy

Replace mock login with **NextAuth** (or your IdP). Protect server actions and route handlers. Map roles in the database, not in React state.

## Week 2 — Database and validation

One schema (Prisma/Drizzle/etc.) as source of truth. **Zod** at every API boundary. Ban duplicate types copied from the builder export.

## Week 3 — Stripe for real

Checkout or Payment Element plus **webhooks** with an idempotency table before you announce pricing. Test `invoice.paid`, failed payments, and plan changes.

```typescript
const existing = await db.stripeEvent.findUnique({ where: { id: event.id } });
if (existing) return new Response("ok", { status: 200 });
await handleStripeEvent(event);
await db.stripeEvent.create({ data: { id: event.id, type: event.type } });
```

## Week 4 — CI/CD

On every PR: `typecheck`, `lint`, `test`, `build`. Preview environments per branch. Smoke test signup → pay → access gated feature.
